feat(actions): add `@bunny.net/actions`, a headless action layer (`{ name, description, schema, destructive, run(ctx, input) }`) that backs the CLI, a future MCP server (`@bunny.net/actions/mcp`), and direct agent imports from one definition. 22 actions cover storage zones (list/get/create/update/delete/credentials), storage files (list/upload/download/delete), and databases (list/get/create/delete/usage, regions available/suggest/list/set, tokens create/invalidate). The CLI wraps them with `defineActionCommand` (prepare -> confirm -> spinner -> after -> render) for single-action commands, and calls `action.invoke()` directly from orchestration commands (`storage zones add`, `db create`, `db tokens invalidate`, `db regions add/remove/update`). Actions never prompt or print and return normalized, credential-free results (camelCase, region names resolved, zone-relative file paths); `sensitive` actions return secrets in full for the host to mask. `--output json` for the converted commands now returns that normalized shape instead of the raw API model, and `storage zones list` gains `--search`.
