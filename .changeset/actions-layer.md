feat(actions): add `@bunny.net/actions`, a headless action layer (`{ name, description, schema, kind, run(ctx, input) }`) that backs the CLI today and can back another host later from the same definitions. Actions cover storage zones (list/get/create/update/delete/credentials), storage files (list/upload/download/delete), databases (list/get/create/delete/usage, regions available/suggest/list/set, tokens create/invalidate), and container registries (list/get/create/update/delete). Every `db` and `storage` command now goes through the layer: single-action commands via `defineActionCommand` (prepare -> confirm -> spinner -> after -> render), orchestration commands (`storage zones add`, `db create`, `db tokens invalidate`, `db regions add/remove/update`, `db shell`, `db studio`, `db quickstart`) by calling `action.invoke()` directly. Actions never prompt or print and return normalized, credential-free results (camelCase, region names resolved, zone-relative file paths); `kind` drives confirmation, and `sensitive`/`localFiles` tell a host what to withhold. `--output json` for the converted commands now returns that normalized shape instead of the raw API model, and `storage zones list` gains `--search`.
